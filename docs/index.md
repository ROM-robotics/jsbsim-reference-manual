# JSBSim ရည်ညွှန်းလက်စွဲ (JSBSim Reference Manual)

![JSBSim Logo](assets/img/logo_jsbsim_globe.svg){: .center width="65%" }

JSBSim သည် လေယာဉ်များအတွက် flight dynamics နှင့် control ကို model ပြုလုပ်ရန် ရည်ရွယ်သည့်၊ ပေါ့ပါးပြီး
data-driven ဖြစ်သော၊ non-linear၊ six-degree-of-freedom (6DoF) batch simulation application တစ်ခု ဖြစ်ပါသည်။
အစောဆုံးဗားရှင်းများမှစ၍ JSBSim သည် ၎င်းကြီးထွားလာခဲ့သည့် open source ဖွံ့ဖြိုးတိုးတက်မှု ပတ်ဝန်းကျင်မှရော၊
၎င်း၏ ဆက်လက်တိုးတက်မှုအတွက် အိုင်ဒီယာများ ပံ့ပိုးပေးခဲ့ကြသော user အမျိုးမျိုးမှလည်းကောင်း
အကျိုးကျေးဇူးများ ခံစားခဲ့ရပါသည်။

ဤအွန်လိုင်း ရည်ညွှန်းလက်စွဲသည် ဆော့ဖ်ဝဲ၏ လုပ်ဆောင်ချက်အားလုံးနှင့်ပတ်သက်၍ user များနှင့် developer များကို
နောက်ဆုံးအခြေအနေအတိုင်း မှတ်တမ်းတင်ထားနိုင်ရန် အသိုင်းအဝိုင်း၏ ပူးပေါင်းကြိုးပမ်းမှု တစ်ခု ဖြစ်ပါသည်။

**လိုင်စင်:** JSBSim ကို GNU Lesser GPL (LGPL) စည်းမျဉ်းများအောက်တွင် လိုင်စင်ပေးထားပါသည်။
